
# Task 5: Host a Static Website with GitHub Pages

## Objective
Deploy a static website using GitHub Pages.

## Technologies Used
- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages

## Project Description
Created a responsive personal portfolio website featuring
an introduction, technical skills, DevOps projects and contact links.

## Deployment Steps
1. Created an index.html file.
2. Uploaded the website to a GitHub repository.
3. Enabled GitHub Pages from repository settings.
4. Selected the main branch and root folder.
5. Verified the published website.

## Learning Outcomes
- Understood static website hosting.
- Practised Git version control.
- Learned to publish a website using GitHub Pages.
- Practised basic responsive web design.
